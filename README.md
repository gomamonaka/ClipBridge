# ClipBridge 1.4.9

## 概要

2台の Windows PC のテキスト・画像クリップボードを、暗号化した OneDrive フォルダー経由で共有する WPF 常駐アプリです。Ctrl を2回押して小さな一覧を開き、履歴と定型文から選んで元のアプリへ貼り付けます。履歴・定型文のグループ管理、CSV・Clibor からの移行、暗号化バックアップにも対応します。

※ このリポジトリは、開発実績としてのソースコード閲覧用です。バイナリ（インストーラー等）の配布は行っていません。ライセンス条件は LICENSE.txt をご覧ください。

1.4.9 では、一覧の背景を淡いミント、選択行をアプリコットにしました。背景のみを約 93% の不透明度にし、文字は不透明のまま読みやすさを保ちます。ウィンドウの四隅は 8 DIP の角丸です。グループ選択欄も同じ色調に揃え、履歴と定型文で上部の高さを統一する動作を維持しています。

1.4.8 では、グループ選択をページ表示と同じ段へ移し、履歴と定型文で上部の高さを統一しました。表示中の高さ変更では現在の上端を保ち、下側に収まる行数へ調整します。Ctrl 2 回での明示的な呼び出し直しは引き続き現在のカーソル位置を使います。

1.4.7 では Clibor の構成にさらに近づけ、上部の 2 分割タブ・アプリ名とページ表示・本文一覧だけを基本とする白とグレーの画面にしました。横幅は 380 DIP です。登録・検索・共有の一時停止・管理は右上の「⋯」メニューから操作します。新着がある場合とメッセージがある場合だけ補助表示が現れます。

1.4.6 では Clibor を参考にメイン画面をコンパクトにしました。横幅 420 DIP、20 DIP の番号付き一行一覧、青い選択表示、薄いグレーのヘッダーを採用しています。日時や端末名はツールチップで確認でき、項目が少ない場合は高さも縮まります。Ctrl 2 回、マウスオーバー切り替え、ホイールでのページ送り、管理・編集機能を引き続き利用できます。

2 台の Windows PC のテキスト・画像クリップボードを、暗号化した OneDrive フォルダー経由で共有する WPF 常駐アプリです。Ctrl を 2 回押して小さな一覧を開き、Enter・クリック・数字／英字で元のアプリへ貼り付けます。履歴／定型文はタブにマウスを重ねても切り替えられます。

1.4.5 では、Ctrl 2 回で一覧が表示されるまでの処理を軽くしました。同じページを再表示するときは行と画面部品を再利用し、呼び出し通知の実行順も調整しました。Ctrl を押して離す操作で呼び出しを確定する動作は維持しています。1.4.4 では利用者から Ctrl 2 回で開くことを確認できた一方、表示の遅れが報告されました。1.4.5 の体感速度は利用者による確認前です。

キーを離した通知の欠落や日本語 IME の状態通知で、Ctrl 2 回が使っている途中から反応しなくなる問題への対策も維持しています。スリープからの復帰や入力監視の異常を検出した場合は自動で監視を復旧し、Ctrl + Alt + V からの呼び出しも復旧のきっかけにします。復旧時の通知は表示しません。

一覧の表示中にもう一度 Ctrl を 2 回押すと、その時点のカーソル位置で履歴を開き直します。別アプリの入力カーソルを取得できる場合はその付近、一覧にフォーカスがある場合は現在のマウスポインター付近に配置し、元の貼り付け先を保持します。Ctrl 2 回では一覧を閉じません。一覧の外をクリックするか Esc を押すと閉じます。管理・編集画面の操作中は、Ctrl 2 回による呼び出し直しを抑制します。

空のグループの作成・名前変更・削除、グループと定型文の並び替え、CSV、Clibor 移行、暗号化バックアップと復元、履歴の編集・テキスト整形に対応します。管理画面の「編集」ボタン・ダブルクリック・F2 から定型文を直接編集できます。共有内容と順序を両方の PC で管理できます。OneDrive 経由の到着時間は同期状況に依存します。

一覧のマウスホイールと PgUp / PgDn でページを切り替えます。1 ページの目安は 25 件で、画面に収まる件数へ自動調整します。定型文欄は登録済みの実グループを管理順で表示し、初回表示・再表示とも先頭のグループから開きます。グループ内のページを進んでから次のグループへ移動し、検索中は同じグループの検索結果をページ送りします。数字・英字は表示中のページ内の項目を選びます。表示中に届いた新しい履歴は更新待ちにし、選ぼうとした行がずれないようにしています。

1.3.2 では、日本語 IME の状態により項目の選択後に一覧が閉じるまで余分に待機する問題を修正しました。実際に押されているキーの解放確認は維持し、「コピーのみ」は自動貼り付けのフォーカス復帰を待たずに一覧を閉じます。履歴選択時には対象の 1 件だけを取得して負荷を抑えます。通知領域のバルーン通知は表示せず、常駐アイコンと画面内の状況表示を使います。

## 開発とビルド

Windows 10 / 11 x64 と .NET SDK 10 が必要です。外部のアプリ用 NuGet ライブラリは使っていません。初回の配布版ビルドでは、公式の .NET ランタイムパックを取得するためネットワーク接続が必要です。

```powershell
.\scripts\build.ps1
```

Release ビルド、同期コア・CSV／移行・ネイティブ連携・WPF の確認、Windows x64 向け自己完結型の単一実行ファイルへの発行、使い方・ランタイムライセンスの同梱を行います。出力先は `artifacts\win-x64` です。CSV と移行処理の確認は次でも実行できます。

```powershell
dotnet run --project tests\ClipBridge.Transfer.Tests\ClipBridge.Transfer.Tests.csproj -c Release
```

2026 年 10 月 18 日のローカル Windows 環境で、1.4.5 のネイティブ連携 131 項目と WPF 201 項目が成功し、Release ビルドは警告・エラーともに 0 件でした。1.4.5 の GitHub Actions による全体検証は未実施です。過去版では、1.4.4 の GitHub Actions で同期コア 34 項目、CSV／移行 59 項目、ネイティブ連携 129 項目、WPF 196 項目の計 418 項目が成功しています。確認範囲とインストーラーの検証は [検証記録](docs/TESTING.md) に記載しています。物理キー・クリックによる操作、実クリップボードへの書き込み、別アプリへの貼り付け、実機 2 台の OneDrive 往復同期は利用環境で確認してください。

Inno Setup 6.7.3 を用意すると、検証・発行済みの実行ファイルからインストーラーを作成できます。

```powershell
.\scripts\build-installer.ps1 -CompilerPath 'C:\Tools\Inno Setup 6\ISCC.exe'
```

出力は `artifacts\release\ClipBridge-<版>-Setup.exe` です。ビルド時に署名用証明書を指定していないため、現状のインストーラーとアプリは未署名です。

合成データで画面を確認する場合は `ClipBridge.exe --demo`、1 ページ 5 件でページ送りを試す場合は `ClipBridge.exe --demo --paged` を使えます。デモは通常のクリップボード監視や接続設定の読み書きを開始しません。

## 構成

- `src/ClipBridge.Core`: 暗号化、共有、履歴、定型文・グループ・並び順、バックアップ、送信待ちキュー
- `src/ClipBridge.App`: WPF 画面、Win32 クリップボード通知、Ctrl 2 回・ショートカット、元のアプリへの貼り付け、CSV・移行、DPAPI 設定保存
- `tests/ClipBridge.Core.Tests`: 分離した一時フォルダーでの同期・復元確認
- `tests/ClipBridge.Transfer.Tests`: 合成データによる CSV・Clibor 変換・取り込み確認
- `tests/ClipBridge.Native.Integration`: 実際のキーフック登録と合成通知の経路確認

共有コアは変更をファイルへ原子的に発行し、500 ms 間隔で到着を確認します。OneDrive の転送完了をアプリから確定する機能はありません。初回は 1 台目の `clipbridge.group.json` が同期されてから 2 台目を接続してください。CSV は平文、バックアップの `.cbb` は合言葉で暗号化されます。
