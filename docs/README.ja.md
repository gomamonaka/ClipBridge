# ClipBridge 1.4.9 の使い方

1.4.9 では、一覧の背景を淡いミント、選択行をアプリコットにしました。背景のみを約 93% の不透明度にし、文字は不透明のまま読みやすさを保ちます。ウィンドウの四隅は 8 DIP の角丸です。グループ選択欄も同じ色調に揃え、履歴と定型文で上部の高さを統一する動作を維持しています。

1.4.8 では、グループ選択をページ表示と同じ段へ移し、履歴と定型文で上部の高さを統一しました。表示中の高さ変更では現在の上端を保ち、下側に収まる行数へ調整します。Ctrl 2 回での明示的な呼び出し直しは引き続き現在のカーソル位置を使います。

1.4.7 では Clibor の構成にさらに近づけ、上部の 2 分割タブ・アプリ名とページ表示・本文一覧だけを基本とする白とグレーの画面にしました。横幅は 380 DIP です。登録・検索・共有の一時停止・管理は右上の「⋯」メニューから操作します。新着がある場合とメッセージがある場合だけ補助表示が現れます。

1.4.6 では Clibor を参考にメイン画面をコンパクトにしました。横幅 420 DIP、20 DIP の番号付き一行一覧、青い選択表示、薄いグレーのヘッダーを採用しています。日時や端末名はツールチップで確認でき、項目が少ない場合は高さも縮まります。Ctrl 2 回、マウスオーバー切り替え、ホイールでのページ送り、管理・編集機能を引き続き利用できます。

2 台の Windows PC のテキストと画像のクリップボードを、OneDrive の同期フォルダー経由で共有する常駐アプリです。**Ctrl を 2 回 → 一覧で選択 → 元のアプリへ貼り付け**の流れで使えます。履歴と定型文のタブにマウスを重ねると、その場で切り替わります。

グループ管理・並び替え、CSV、暗号化バックアップ・復元、履歴の編集・整形、管理画面からの定型文編集に対応します。マウスホイールでページと定型文グループを切り替えられます。定型文欄は、登録済みの実グループを管理順で表示します。端末間の到着時間は OneDrive とネットワークの状態に左右されます。

1.4.5 では、Ctrl 2 回で一覧を表示するときの処理を軽くしました。呼び出し方と設定は従来どおりで、Ctrl を押して離す操作を 2 回行います。1.4.4 で呼び出せることは利用者から確認できていますが、1.4.5 の体感速度は確認前です。

## 起動と更新

Windows 10 / 11 の 64 ビット版で利用できます。[Release ページ](https://github.com/gomamonaka/ClipBridge/releases) は Private のため、アクセス権のある GitHub アカウントでサインインして開きます。

1. 通知領域の ClipBridge アイコンを右クリックし、動作中の旧版を **終了**します。× ボタンは画面を閉じるだけです。
2. 各 PC で `ClipBridge-1.4.9-Setup.exe` を実行します。管理者権限は不要で、日本語の画面に従って進めます。
3. 必要に応じてデスクトップのショートカットと **Windows と一緒に起動する**を選びます。自動起動の初期選択は既存の設定を引き継ぎます。
4. 完了画面から起動するか、スタートメニューの **ClipBridge**を開きます。

標準のインストール先は `%LOCALAPPDATA%\Programs\ClipBridge` です。同じ Windows ユーザーの接続設定・履歴・定型文を引き継ぐため、Clibor の移行データを取り込み直す必要はありません。両方の PC へインストールしてください。配布版は .NET ランタイムを含みます。

ZIP を任意のフォルダーへ展開し、`ClipBridge.exe` を起動するポータブル版も利用できます。インストーラーへ切り替えた後はスタートメニューから起動します。以前 OneDrive 内に置いた古い実行ファイルを再び開かないようにしてください。

アンインストールは Windows の **設定 → アプリ → インストールされているアプリ → ClipBridge**から行います。接続設定・履歴などのローカルデータと OneDrive 上の共有データは残ります。自動起動は、このインストール先を指す登録だけを解除します。

## 2 台の PC を接続する

1. 両方の PC で OneDrive のデスクトップ同期を動作させ、同じ OneDrive 上の専用フォルダーを用意します。
2. 両方で、そのフォルダーを右クリックし **このデバイス上で常に保持する**を選びます。Windows の **時刻を自動的に設定する**も有効にします。
3. **先に 1 台目だけ**で ClipBridge を起動し、専用フォルダー、端末名、12 文字以上の共通の合言葉を設定します。
4. 作成された `clipbridge.group.json` が **2 台目に同期されてから**、2 台目で同じ専用フォルダーと合言葉を設定します。初回設定を同時に行わないでください。
5. 架空のテキストを片方でコピーし、相手に届くことを確認します。逆方向も確認してください。

PC ごとのローカルパスは異なっていても、OneDrive 上で同じフォルダーなら接続できます。端末名を変えると履歴のコピー元を見分けられます。Microsoft アカウントへのサインインとフォルダー共有は OneDrive 側で行います。

## 日常の操作

| 操作 | 方法 |
| --- | --- |
| 履歴を開く | **Ctrl をすばやく 2 回**、または **Ctrl + Alt + V** |
| 表示中の一覧を現在の位置へ呼び直す | もう一度 **Ctrl をすばやく 2 回** |
| 定型文を開く | **Ctrl + Alt + Space** |
| 履歴／定型文の切り替え | 上部のタブにマウスを重ねる、クリック、または **← / →** |
| 一覧で選ぶ | **↑ / ↓** |
| ページを切り替える | 一覧の上で **マウスホイール**、または **PgUp / PgDn** |
| 選んだ内容を使う | **Enter**、項目を 1 回クリック、または表示された **1〜0 / A〜Z** |
| 検索 | **Ctrl + Shift + F** または **Ctrl + F** |
| 定型文を登録 | **＋ 登録** または **Ctrl + Shift + N** |
| ページ件数・末尾の動作を変更 | **… → ページ切り替え設定…** |
| 履歴・定型文を編集 | **F2**、または項目の右クリックメニュー |
| 履歴から定型文を作る | 履歴を右クリック → **定型文に登録…** |
| 自動貼り付けせずコピー | 右クリック → **コピーのみ**、または **Ctrl + C** |
| 項目を削除 | 右クリック → **削除**、または **Delete** |
| 画面を閉じて常駐 | **Esc**、**×**、または一覧の外をクリック |

通常は、呼び出す直前のアプリへ戻って **Ctrl + V** を送ります。通知領域の **操作設定**で自動貼り付けと Ctrl 2 回の呼び出しを個別に変更できます。自動貼り付けを無効にするとコピーだけを行い、手動で Ctrl + V を押せます。検索欄の入力中は数字・英字も検索文字になります。

一覧が開いている間も、Ctrl を 2 回押すと履歴を現在のカーソル位置へ呼び直せます。別アプリの入力カーソルを取得できる場合はその付近、取得できない場合はマウスポインター付近に開きます。一覧にフォーカスがあるときは現在のマウスポインター付近へ移動し、呼び出し元の貼り付け先を保持します。表示位置は画面内に収まるよう調整します。**Ctrl 2 回は呼び出す操作**で、閉じるには一覧の外をクリックするか Esc を押してください。管理・編集画面や確認ダイアログの操作中は、Ctrl 2 回で背後の一覧を呼び直しません。

1.3.2 では、日本語 IME が有効なときに、左クリックなどで項目を選んだ後も一覧が余分に待機する問題を修正しています。**コピーのみ**では、自動貼り付けのフォーカス復帰を待たずに一覧を閉じます。Enter や Ctrl + C などを押し続けている場合は、キーの繰り返し入力が他のアプリへ入らないよう、実際のキー解放を確認します。通知領域のバルーン通知は表示しません。常駐アイコンのメニューと、画面内の共有状況・メッセージから状態を確認できます。

Ctrl は押して離す操作を 2 回行ってください。Ctrl + C などの組み合わせやアプリが送ったキー入力は呼び出しとして扱いません。1.4.4 では、キーを離した通知の欠落や日本語 IME の状態通知によって、使っている途中で Ctrl 2 回が反応しなくなる問題を修正しました。スリープ復帰や入力監視の異常を検出すると、自動で監視を復旧します。履歴を **Ctrl + Alt + V** で開くことも復旧のきっかけになります。復旧の通知は表示しません。Clibor と併用して呼び出しが重なる場合は、どちらかの Ctrl 2 回を無効にしてください。

元のアプリへフォーカスを戻せない場合はコピーだけを残します。管理者権限のアプリなどでは自動貼り付けできないことがあります。相手からの受信時は履歴とクリップボードを更新し、アプリへのキー入力は送りません。

## ホイールでページとグループを切り替える

一覧の上でホイールを下へ回すと次、上へ回すと前へ移動します。**PgDn / PgUp** でも同じページ送りができます。

| 表示中の一覧 | ページ送りの動作 |
| --- | --- |
| 履歴 | 履歴をページ単位で進む・戻る |
| 定型文 | 選択中のグループ内をページ送りし、最後のページの次で次のグループへ移る。前方向も同じ順序で戻る |
| 検索結果 | 選択中のグループを変えずに検索結果をページ送りする |

定型文のグループ欄には、登録済みの実グループを **管理画面の並び順**で表示します。初めて定型文を開いたときや、画面を閉じて開き直したときは、先頭の実グループの 1 ページ目から始まります。グループの最後のページから進むと次のグループの先頭ページへ、先頭ページから戻ると前のグループの最後のページへ移ります。

初期設定は **1 ページ 25 件を目安**にします。画面の高さに合わせて実際の件数を減らすため、低い画面や拡大表示では 25 件より少なくなることがあります。**… → ページ切り替え設定…** では 1〜36 件を指定し、末尾から先頭へ戻るループも切り替えられます。初期設定はループしません。ページ設定はこの PC ごとの設定です。

タブやグループの選択欄で切り替えて戻ると、それぞれのページ位置と検索条件を保持します。表示された **1〜0 / A〜Z** は、現在のページ内の項目に対応します。次のページでも先頭から同じキーを使えます。検索欄の入力中は数字・英字が検索文字になる点は従来と同じです。

履歴を開いている間に新しいコピーが届いても、表示中の行を途中でずらしません。**新着 N 件を表示**または **履歴を更新**ボタンで新しい履歴を反映するか、画面を閉じて開き直してください。履歴への保存と端末間の共有は表示の更新を待たずに続きます。画面を閉じて呼び出し直すと、検索を解除して最新の先頭ページから開きます。

定型文や履歴の編集画面では、ホイールは本文などの通常のスクロールに使います。

## グループと並び順を管理する

定型文タブの **管理**、または右上の **… → グループ管理・並び替え…** を開きます。

1. 左下の名前欄に入力して **新規作成**を押すと、定型文がない空のグループも作れます。名前は 60 文字以内です。
2. 左のグループを選び、名前欄を書き換えて **名前変更**を押します。
3. グループの上にある **↑ / ↓** でグループの表示順を変更します。
4. 右の定型文を選び、右側の **↑ / ↓** でグループ内の順序を変更します。下の移動先を選んで **移動する**を押すと別のグループへ移せます。
5. 定型文を選んで **編集**、**F2**、またはダブルクリックすると、タイトル・本文・グループを編集できます。編集ダイアログの **保存する**で管理画面に戻ります。
6. 管理画面の **変更を保存**で、編集と並び順をまとめて確定します。管理画面をキャンセルすると定型文の編集も含めて破棄します。

グループを削除すると、中の定型文を **共通**へ移動します。共通グループは名前変更・削除できません。グループ、定型文の内容と並び順は 2 台へ共有されます。定型文の登録・編集画面から、新しいグループ名を直接入力する方法も使えます。編集中の定型文を別の端末でも変更した場合は、上書きせずに保存を止めて通知します。

## 定型文の CSV 取り込み・書き出し

右上の **… → 定型文を CSV から取り込む…** または **定型文を CSV に書き出す…** を選びます。取り込み前には自動バックアップを保存します。確認画面で件数と注意を確認してから実行してください。

ClipBridge の CSV は UTF-8 で書き出し、空グループ・並び順・定型文の複数行本文を保持します。表計算ソフトで編集するときは、ID の変更を避け、本文中のカンマ・改行・引用符を CSV の引用符で囲んだ状態を保ってください。

```csv
種別,ID,グループ,タイトル,本文,並び順
group,,仕事,,,0
snippet,,仕事,確認のお願い,ご確認のほどよろしくお願いいたします。,0
```

ID を空欄にした新規データも取り込めます。既存の ID がある行はその定型文を更新します。ID がない場合はグループ・タイトル・本文がすべて一致する既存項目の重複を避け、本文が異なるものは別の定型文として追加します。CSV は 50 MiB 以下、グループ 256 件、定型文 5,000 件までです。UTF-8、UTF-16、CP932 の読み込みに対応します。

**CSV は暗号化されない平文ファイルです。** 機密の定型文を含む場合は保存先と取り扱いを確認してください。履歴を含めて暗号化して保管する場合は次のバックアップを使います。

## Clibor のデータを移行する

Clibor で書き出した定型文 CSV は、**… → Clibor から移行…** または CSV 取り込みから読み込めます。Clibor CSV の見出しは次の形式です。

```csv
定型文グループ,定型文,メモ,ホットキー
```

グループ名を保持し、**メモをタイトル、定型文を本文**に対応させます。メモが空の場合は本文からタイトルを作ります。ホットキー設定は引き継ぎません。`<$CLB_...>` などの Clibor 独自マクロは実行せず、文字列として保持するため、必要に応じて本文を編集してください。

移行メニューは専用形式へ変換した移行 JSON にも対応します。Clibor のデータベースをそのまま選択する方式ではありません。CSV は定型文の移行用です。履歴や空グループを含む変換済みデータを受け取った場合は、その JSON を選択してください。移行元の Clibor ファイルは変更しません。

## バックアップと復元

**… → バックアップを作成…** で履歴・定型文・グループ・並び順を `.cbb` ファイルに保存します。**作成時の共通の合言葉で暗号化され、復元にもその合言葉が必要です。** 合言葉を忘れると復元できません。

復元は **… → バックアップから復元…** を開き、ファイルと作成時の合言葉を指定します。定型文・グループは追加・更新し、履歴は現在登録されていないものを追加します。削除・編集した履歴の元の本文も、バックアップにあれば追加で取り戻せます。バックアップに含まれない現在の項目と編集後の履歴は残します。接続先や端末名など、この PC の設定はバックアップの対象外です。復元した内容は接続中の相手にも共有されます。

CSV・Clibor の取り込み、グループ変更、復元の前には、`%LOCALAPPDATA%\ClipBridge\Backups` に暗号化した自動バックアップを保存します。元の合言葉を保持し、必要なバックアップを別の保存先へ保管してください。

## 履歴を編集・整形する

テキスト履歴を選び **F2**、または右クリック → **履歴を編集・整形…** を開きます。本文を直接編集でき、次の操作をボタンで適用できます。

- 行頭・行末の空白を削除、空行を削除、改行をスペースで連結
- 大文字・小文字への変換、英数字・記号・空白の全角／半角変換
- 通常の文字列置換、正規表現による置換（`$1` などのキャプチャを利用可能）

**Ctrl + Z** で整形を取り消し、**元の内容に戻す**で編集開始時の本文へ戻せます。内容を確認して **履歴に保存**または **Ctrl + Enter** を押してください。保存するまで履歴に反映しません。保存した編集は相手にも共有されます。画像の履歴はこの画面で編集できません。

## 保存上限と同期

| 項目 | 上限 |
| --- | --- |
| 履歴 | 2,000 件、テキスト・画像の合計 96 MiB |
| 定型文 | 5,000 件、本文は各 64 KiB（UTF-8） |
| グループ | 共通を含め 256 件、名前は各 60 文字 |
| 共有・編集するテキスト | 各 1 MiB（UTF-8） |
| 共有する画像 | PNG 換算で 8 MiB、3,200 万画素 |
| 未送信データ | 8,192 操作、保存形式で 96 MiB |

暗号化キャッシュ全体は 256 MiB までのため、内容によっては件数上限より早く古い履歴を整理します。取り込み・復元後の上限を超える場合はエラーになり、取り込み前の内容を保持します。

オフライン中はローカルに保存し、再接続後に共有します。起動前のコピーや遅れて届いた過去のデータは履歴だけに取り込み、起動時に現在のクリップボードを過去の内容へ置き換えません。共有フォルダー内のコピー記録は作成から 7 日を過ぎると定期的に整理し、取り込み済みの履歴は各 PC の件数・容量上限に従って保持します。

## 保存とプライバシー

共有フォルダーとローカルの履歴キャッシュは AES-GCM で暗号化し、合言葉から PBKDF2 で鍵を生成します。この PC の合言葉は Windows のユーザー保護機能（DPAPI）で保護して保存します。ローカルの設定とキャッシュは `%LOCALAPPDATA%\ClipBridge` にあります。設定には端末名とフォルダーのパスも含まれます。

共有フォルダーと共通の合言葉を持つ端末は内容を読めます。実行中のアプリと Windows クリップボードでは、貼り付けのために復号した内容を扱います。画面からの削除は共有先にも反映しますが、OneDrive のごみ箱・バージョン履歴や過去の暗号化ファイルを直ちに完全消去する操作ではありません。

対象はプレーンテキストと画像です。ファイルやリッチテキストの書式は共有しません。コピー元アプリが Windows のクリップボード履歴・クラウド同期の除外形式を付けている内容は、その指定に従います。

## 届かない・呼び出せない場合

- 両方で ClipBridge と OneDrive が動作し、同じ専用フォルダー・合言葉を指定しているか確認します。
- OneDrive の一時停止、同期エラー、容量不足を確認し、フォルダーを **このデバイス上で常に保持する**にします。
- 両方の Windows で時刻を同期します。
- Ctrl 2 回が反応しない場合は、通知領域の **操作設定**で有効になっているか確認します。履歴は **Ctrl + Alt + V** や通知領域からも開けます。1.4.4 では Ctrl + Alt + V で開いた際に入力監視の復旧も依頼します。キーをすべて離してから、Ctrl 2 回を試してください。
- 旧版が残っている場合は通知領域から終了し、新版を起動し直します。他のアプリとのキー競合も確認してください。

実機での受け入れ手順と自動検証の範囲は [TESTING.md](TESTING.md) を参照してください。
