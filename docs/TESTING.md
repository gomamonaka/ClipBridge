2026 年 10 月 20 日のローカル Windows 環境で Release ビルド（警告・エラー 0 件）、ネイティブ連携 134 / 134、WPF 209 / 209 が成功しました。WPF には、ウィンドウ全体をラスタライズして四隅が透明であること、通常行の背景に実際の半透明アルファが残ること、文字へウィンドウ全体の不透明度を掛けていないこと、暖色の選択表示、幅・表示セクション変更後の角丸維持、グループ選択欄のキーボードフォーカスとドロップダウンを確認する 6 項目を追加しました。上部の高さ、ページ切り替え、行再利用、外側クリックで閉じる回帰確認も成功しています。

合成データの画面を 144 DPI で生成して目視確認しました。背景は淡いミント（基本面の不透明度 237 / 255 ≒ 93%）、選択行はアプリコット、角丸は 8 DIP です。管理画面や利用者の保存設定は変更していません。

測定プログラムでは検索パスによって古い DLL が優先されることを検出し、参照元の優先順を修正してから上記の比較を行いました。不一致だった初回結果は採用していません。記録は外部の `work/popup-latency-bench/runs/v1.4.8-pastel-baseline-final/result.json` と `v1.4.9-pastel-candidate/result.json` です。候補版の測定後にグループ一覧の配色を揃え、WPF の全 209 項目を再実行しました。

## 1.4.4 の Ctrl 2 回と入力監視の復旧

2026 年 10 月 18 日の修正対象は、Ctrl + Alt + V では一覧が開く一方、Ctrl 2 回だけが途中から反応しなくなる問題です。検証用の入力経路で、キーを離した通知の欠落と、日本語 IME の状態通知によって押下中の状態が残る条件を再現しました。利用者の実行中プロセスで同じ原因が発生したと断定するものではありません。

物理キーに該当しない通知を除き、残った押下状態を現在のキー状態と照合して回復すること、Ctrl + C などを押している状態では呼び出さないことを確認しました。入力監視の異常やスリープ復帰相当の時間経過からの監視復旧、Ctrl + Alt + V による復旧要求も対象です。正常な監視を定期的に作り直す動作は避け、復旧を通知するバルーンも追加していません。

## 再検証するコマンド

Windows と .NET 10 SDK を用意し、ソースコードのルートフォルダーで実行します。

```powershell
dotnet build src\ClipBridge.App\ClipBridge.App.csproj -c Release
dotnet run --project tests\ClipBridge.Core.Tests\ClipBridge.Core.Tests.csproj -c Release
dotnet run --project tests\ClipBridge.Transfer.Tests\ClipBridge.Transfer.Tests.csproj -c Release
dotnet run --project tests\ClipBridge.Native.Integration\ClipBridge.Native.Integration.csproj -c Release -- "$PWD\artifacts\native-integration.json"
.\src\ClipBridge.App\bin\Release\net10.0-windows\ClipBridge.exe --self-test "$PWD\artifacts\ui-test.txt"
```

一括検証と自己完結型の配布版発行は `scripts\build.ps1` で行えます。画面だけを見る場合は `ClipBridge.exe --demo` を使います。`ClipBridge.exe --demo --paged` では、架空の項目を 1 ページ 5 件で表示し、ページ送りを試せます。`--demo` と `--self-test` は通常のクリップボード監視や接続設定の読み書きを開始しません。

## コピー元アプリの除外指定

開発用のテストプログラムで、架空の Unicode テキストと次の登録形式をクリップボードに設定し、保存・共有を除外することを確認します。

- `ExcludeClipboardContentFromMonitorProcessing` が存在する
- `CanIncludeInClipboardHistory` に DWORD の `0` が入っている
- `CanUploadToCloudClipboard` に DWORD の `0` が入っている

保存上限は履歴 2,000 件・96 MiB、定型文 5,000 件、グループ 256 件です。これらの境界条件は合成データによる自動検証の対象であり、日常の確認のために実データを上限まで増やす必要はありません。
